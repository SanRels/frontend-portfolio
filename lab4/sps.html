Контекст и архитектурные слои

Электронная образовательная среда объединяет учебные материалы, сдачу работ и выставление оценок. Студент отправляет работу, преподаватель проверяет её, администратор управляет доступом и эксплуатацией.

Представление

Веб-кабинеты показывают курсы, задания, сроки и результаты.

Прикладная логика

Сервер проверяет роли, сроки сдачи и переходы между состояниями работы.

Данные

База хранит курсы, записи о работах и оценки. Файлы хранятся отдельно.

Ключевые компоненты

Курсы и задания

Публикует материалы, задания и сроки для учебных групп.

Работы и оценки

Регистрирует попытки сдачи и сохраняет оценку и комментарий преподавателя.

Доступ и уведомления

Проверяет права на стороне сервера. Фоновый обработчик отправляет напоминания и сообщения об оценках.

Интерфейсы и обмен данными

Пользовательский интерфейс

Студент загружает файл через форму. Преподаватель открывает список работ курса и публикует результаты.

Программные интерфейсы

Браузер обращается к REST API по HTTPS. Запрос POST /api/submissions передаёт идентификатор задания и файл. Сервер проверяет доступ и срок, сохраняет файл, регистрирует работу и возвращает её идентификатор.

Технологический стек и развитие

Возможный стек системы включает HTML, CSS и JavaScript в браузере, Node.js на сервере, PostgreSQL для записей и объектное хранилище для файлов.

Направления развития включают единый вход через OpenID Connect, журналирование действий и повторную отправку уведомлений после временных сбоев.
