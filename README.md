# Frontend Portfolio

Учебный веб-проект по дисциплине **«Введение во фронтенд разработку»**.

Проект развивается на протяжении курса: каждая лабораторная работа
добавляет новые возможности к одному сайту — от базовой HTML-разметки
до адаптивного и интерактивного веб-проекта.

## 👨‍💻 О проекте

Итоговый проект представляет собой личный сайт-визитку, состоящий
из нескольких связанных страниц:

- 🏠 Главная
- 👤 Обо мне
- 👥 Друзья
- 🎯 Увлечения
- 🎓 Группа

## 📚 Этапы разработки

| № | Лабораторная работа | Статус |
|---|----------------------|--------|
| 1 | Введение в HTML. Базовая структура документа | ✅ |
| 2 | Семантическая разметка HTML5. Гиперссылки и изображения | ⬜ |
| 3 | Основы CSS. Селекторы и стилизация текста | ⬜ |
| 4 | CSS-макеты. Блочная модель, Flexbox и Grid | ⬜ |
| 5 | Адаптивная вёрстка. Медиазапросы | ⬜ |
| 6 | Формы и таблицы в HTML | ⬜ |
| 7 | Декоративные эффекты CSS | ⬜ |
| 8 | Основы JavaScript. DOM и события | ⬜ |
| 9 | Публикация веб-проекта и защита портфолио | ⬜ |

**Обозначения:**  
✅ — выполнено · 🔄 — в работе · ⬜ — не начато
